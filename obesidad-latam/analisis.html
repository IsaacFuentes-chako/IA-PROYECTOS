1. Introducción

Los niveles de obesidad representan un problema de salud pública de gran relevancia en América Latina. Investigadores de la Universidad de la Costa (Colombia) recopilaron información de individuos provenientes de Colombia, Perú y México con el objetivo de estudiar los factores asociados a distintos niveles de obesidad, clasificados a partir del índice de masa corporal (IMC).

Objetivo general.

Elaborar un reporte técnico que documente el proceso de análisis exploratorio y de inferencia realizado sobre el conjunto de datos brindado, de tal forma que el lector pueda comprender completamente la metodología, los resultados y las conclusiones sin necesidad de revisar el código.

Objetivos específicos.

Este reporte cubre los siguientes cuatro objetivos:

  1. Realizar una exploración inicial de los datos que permita comprender su estructura, tamaño y tipo de información.
  2. Reflexionar, desde una perspectiva crítica de diseño de estudio, sobre una variable adicional relevante que se hubiera podido medir.
  3. Definir y justificar una variable de salida adecuada para un estudio de inferencia, y describirla de forma descriptiva.
  4. Realizar un análisis gráfico en una subpoblación específica, explorando la relación entre la variable de salida y una variable cuantitativa de interés.

2. Metodología

Esta sección describe y justifica las decisiones tomadas durante el análisis, explicando cómo cada una se relaciona con los objetivos del estudio.

2.1 Fuente de datos y herramientas. Se utilizó el archivo A1.1 Obesidad.csv, una versión simplificada de la base de datos original del UCI Machine Learning Repository. El análisis se realizó en Python, empleando la librería pandas para la manipulación de datos y matplotlib para la generación de las figuras. Todo el procesamiento se documenta y ejecuta dentro de este mismo notebook, de modo que los resultados sean reproducibles.

2.2 Estrategia general de análisis. El análisis se dividió en cuatro, cada parte diseñada para cubrir uno de los objetivos específicos planteados:

  • 1.— Exploración inicial: antes de interpretar cualquier resultado, es necesario conocer el tamaño de la muestra, el tipo de cada variable (cuantitativa o cualitativa) y verificar la calidad de los datos (por ejemplo, valores faltantes). Esta etapa es la base que sustenta todo el análisis posterior, si no conocemos la naturaleza de cada variable no sería posible elegir correctamente las técnicas descriptivas o gráficas adecuadas para cada una.

  • 2.— Reflexión de diseño: se analizó qué información relevante podría estar ausente del conjunto de datos. La decisión de qué variable proponer se basó en identificar qué determinantes conocidos de la obesidad, según la literatura de salud pública: alimentación, genética, actividad física; no están representados en las variables disponibles.

  • 3.— Selección de la variable de salida: para elegir la variable de respuesta se utilizó como criterio que la variable debía sintetizar el fenómeno central que el estudio busca explicar: el nivel de obesidad. Por esta razón se descartaron variables como Peso o Sexo, que pueden verse más como variables explicativas, y se seleccionó NivelDeObesidad, que es además la variable que los propios investigadores originales calcularon como resultado a partir del IMC. Se decidió describirla mediante frecuencias y porcentajes por categoría, dado que es una variable cualitativa ordinal, para lo cual las medidas de tendencia central típicas de variables numéricas no son apropiadas.

  • 4.— Análisis gráfico por subpoblación: se decidió trabajar con la subpoblación femenina y se seleccionó la variable cuantitativa Peso como variable de interés, en lugar de Edad, Estatura, ComeVegetales o ConsumoDeAgua, porque el peso corporal es, junto con la estatura, uno de los dos insumos directos utilizados para calcular el IMC y, por lo tanto, el NivelDeObesidad. Esto permite verificar, como parte del análisis, que la variable de salida se comporta de manera consistente con su definición matemática, además de ilustrar de forma clara el tipo de relación que puede visualizarse con un boxplot.

2.3 Técnicas empleadas. Se utilizaron estadísticas descriptivas (medias, desviaciones estándar, mínimos, máximos, frecuencias y porcentajes) para resumir las variables, y dos tipos de gráfica: un gráfico de barras para representar la distribución de una variable categórica (NivelDeObesidad), y un boxplot para comparar la distribución de una variable cuantitativa (Peso) entre las distintas categorías de la variable de salida dentro de la subpoblación femenina. Ambas técnicas son apropiadas para el tipo de dato analizado en cada caso y permiten una interpretación visual directa sin necesidad de pruebas estadísticas adicionales, ya que el objetivo de esta actividad es exploratorio y descriptivo.

3.2 Reflexión sobre el diseño del estudio

Si se formara parte del equipo de investigación original, una variable adicional que sería relevante incorporar es el nivel de actividad física, medido en minutos de ejercicio por día.

Justificación.

El conjunto de datos actual captura hábitos alimenticios (consumo de vegetales, consumo de calorías) y algunos hábitos de riesgo (tabaquismo), pero no incluye ninguna medida directa de la actividad física de los individuos. La relación entre las calorías consumidas y las calorías gastadas es uno de los determinantes fisiológicos más directos del peso corporal y, por lo tanto, del nivel de obesidad. Sin esta variable, el análisis solo puede explicar el fenómeno desde el lado del consumo, dejando fuera un componente fundamental, lo cual limita la capacidad del estudio para distinguir, por ejemplo, entre una persona sedentaria y una persona activa que consumen calorías similares.

Naturaleza de la variable.

Esta variable sería de tipo cuantitativa continua (minutos de actividad física por día), aunque también podría recolectarse de forma cualitativa ordinal si se optara por categorías como "sedentario", "moderadamente activo" y "activo". La versión cuantitativa es preferible porque permite un análisis estadístico más flexible por ejemplo, calcular correlaciones o construir modelos de regresión.

3.3 Variable de interés para inferencia

Como variable de salida para un estudio de inferencia se selecciona NivelDeObesidad, ya que resume, en una sola categoría, el resultado de salud que el estudio busca explicar y predecir a partir del resto de las variables (demográficas, de hábitos y antecedentes familiares). Es una variable cualitativa ordinal, ya que sus siete categorías siguen un orden lógico de menor a mayor nivel de obesidad: Insufficient_Weight, Normal_Weight, Overweight_Level_I, Overweight_Level_II, Obesity_Type_I, Obesity_Type_II y Obesity_Type_III.

A continuación se presenta un análisis descriptivo de esta variable, mostrando la distribución de sus categorías.

La distribución de NivelDeObesidad está razonablemente equilibrada entre las siete categorías, con frecuencias que oscilan entre 272 individuos (12.9%) en la categoría de peso insuficiente y 351 individuos (16.6%) en obesidad tipo I. En conjunto, las categorías que reflejan sobrepeso u obesidad (Overweight_Level_I a Obesity_Type_III) agrupan a la mayoría de la muestra.

Este resultado vale la pena analizarlo. En realidad, México y Perú tienen tasas muy altas de sobrepeso y obesidad: en México, más del 70% de los adultos tiene exceso de peso (38.3% sobrepeso y 36.9% obesidad, según la Ensanut 2022; Campos-Nonato et al., 2023), y en Perú la cifra ronda el 60% entre sobrepeso y obesidad (Álvarez-Dongo et al., 2019). Colombia tiene una tasa más baja, pero también en aumento. Es decir, en estos países la mayoría de la población sí tiene algún grado de sobrepeso u obesidad, no peso normal.

Sin embargo, lo que sigue sin ser realista es que las siete categorías estén tan parejas entre sí (todas entre 12% y 17%). En la vida real, categorías como obesidad tipo II o tipo III son mucho menos comunes que el sobrepeso leve o la obesidad tipo I. Esto se debe a que el 77% de los datos fue generado artificialmente con la técnica SMOTE para balancear las clases (solo el 23% son datos reales de encuestas), tal como reportan Palechor y de la Hoz Manotas (2019). Por eso, aunque los porcentajes por categoría no reflejan la proporción real, sí es consistente con la realidad que el sobrepeso y la obesidad en conjunto sean un problema que afecta a la mayoría de la población en estos países.

3.4 Análisis gráfico enfocado en una subpoblación

Para este análisis se selecciona la subpoblación femenina, y se explora la relación entre la variable de salida NivelDeObesidad y la variable cuantitativa Peso (en kilogramos).

El boxplot muestra una tendencia clara y creciente entre el nivel de obesidad y el peso corporal en la subpoblación femenina. A medida que se avanza de la categoría Peso insuficiente hacia Obesidad tipo III, el peso típico aumenta de forma constante: pasa de un promedio cercano a 48 kg en peso insuficiente hasta superar los 115 kg en obesidad tipo III.

También se observan otros patrones importantes:

  • La dispersión aumenta en las categorías intermedias: en sobrepeso y obesidad tipo I y II, el rango de pesos es más amplio que en los extremos. Esto sugiere que hay distintas combinaciones de estatura y peso que pueden llevar a una persona a caer en estas categorías.

  • Los grupos se separan bien entre sí: al comparar categorías alejadas entre ellas, como peso normal y obesidad tipo II, casi no hay traslape en los pesos. Esto confirma que el peso es una buena variable para distinguir el nivel de obesidad.

  • Hay algunos valores atípicos: en obesidad tipo I y tipo II aparecen algunas mujeres con un peso fuera de lo típico para su categoría. Esto probablemente se debe a diferencias en la estatura de cada persona.

Este resultado era el esperado. El IMC se calcula dividiendo el peso entre la estatura al cuadrado, y el nivel de obesidad se define a partir del IMC, por lo que era natural encontrar una relación fuerte entre el peso y el nivel de obesidad. Esto confirma que los datos son consistentes: la variable de salida se comporta tal como debería, dado cómo fue construida. Lo interesante que aporta el análisis es ver qué tan dispersos están los pesos dentro de cada categoría. Esto deja ver que la estatura también influye bastante, y que el peso por sí solo no define perfectamente la categoría de cada persona, por eso aparecen esos valores atípicos.

4. Conclusiones

El conjunto de datos analizado está completo, sin valores faltantes, y contiene 2,111 observaciones con 10 variables de distintos tipos: algunas cuantitativas (como edad, estatura y peso) y otras cualitativas (como sexo o antecedentes familiares de sobrepeso). Esto permitió trabajar directamente con los datos, sin necesidad de un proceso largo de limpieza previo al análisis.

Al reflexionar sobre el diseño del estudio, se identificó que falta una variable importante: el nivel de actividad física. El peso de una persona depende tanto de lo que consume como de lo que gasta en energía, y este conjunto de datos solo captura el lado del consumo. Agregar una variable como los minutos de ejercicio por día ayudaría a entender mejor por qué dos personas con hábitos alimenticios parecidos pueden terminar en categorías de obesidad distintas.

Para el estudio de inferencia, se eligió NivelDeObesidad como variable de salida, ya que es la que resume el fenómeno que se quiere explicar. Su distribución resultó bastante pareja entre las siete categorías, pero esto no se debe a que así sea la realidad, sino a que los datos fueron balanceados a propósito combinando información real con datos generados sintéticamente. Por eso, estos porcentajes no deben tomarse como una estimación de qué tan común es cada nivel de obesidad en la población real.

Finalmente, al analizar la subpoblación femenina se encontró una relación fuerte y clara entre el peso corporal y el nivel de obesidad: entre más alto el nivel de obesidad, mayor el peso. Este resultado tiene sentido, ya que el peso es una de las variables que se usa directamente para calcular el IMC, que a su vez define el nivel de obesidad. Esto confirma que los datos son consistentes entre sí y que se comportan como se esperaría, lo cual da confianza para usarlos en análisis más profundos en el futuro.

En conjunto, este reporte logra explicar de manera clara el proceso de análisis exploratorio y de inferencia realizado sobre el conjunto de datos de obesidad, cubriendo cada uno de los objetivos planteados al inicio.
